# Task 5: Exploratory Data Analysis (EDA)

## 📌 Project Overview
This project focuses on performing **Exploratory Data Analysis (EDA)** on the Titanic dataset using Python. The goal is to explore the dataset, identify patterns and trends, understand relationships between variables, and extract meaningful insights through data visualization and statistical analysis.

## 🎯 Objectives
- Understand the dataset structure and features.
- Identify missing values and examine data quality.
- Generate descriptive statistics.
- Explore relationships between variables.
- Visualize distributions, patterns, and outliers.
- Summarize key findings from the analysis.

## 🛠️ Tools and Technologies
- **Python**
- **Jupyter Notebook**
- **Pandas** – data manipulation and analysis
- **Matplotlib** – data visualization
- **Seaborn** – statistical visualization

## 📂 Files in This Repository
- `5.EDA.ipynb` – Jupyter Notebook containing the analysis, code, visualizations, and observations.
- `titanic.csv` – Dataset used for the analysis. Replace this name if your CSV has a different filename.
- `EDA_Report.pdf` – Report summarizing the analysis and findings.
- `README.md` – Project documentation.

## 📊 Analysis Performed
1. Loaded and inspected the dataset.
2. Examined dataset information and descriptive statistics.
3. Checked missing values.
4. Analyzed categorical variables using value counts.
5. Created histograms and bar charts to understand data distributions.
6. Used boxplots to examine outliers.
7. Created scatterplots and pairplots to explore relationships between variables.
8. Used a correlation heatmap to examine relationships among numerical features.
9. Compared survival patterns across passenger characteristics.
10. Summarized observations and conclusions.

## 🔍 Key Areas of Exploration
- Passenger survival rates
- Gender and survival
- Passenger class and survival
- Age and fare distributions
- Missing values and outliers
- Relationships between numerical variables
